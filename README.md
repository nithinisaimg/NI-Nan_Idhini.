# 🌸 About

**NI – Nan Idhini** (meaning *"I Am Here"* in Kannada) is an AI-assisted emotional wellness platform designed to provide users with a safe and supportive space to express their thoughts and emotions.

Using Natural Language Processing (NLP), the platform analyzes user messages, understands emotional patterns, and offers personalized recommendations, calming activities, and supportive responses.

The project aims to promote mental well-being through technology while emphasizing empathy, accessibility, and privacy.

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/nithinisaimg/NI-Nan_Idhini..git
```

## Navigate to the project

```bash
cd ni-nan-idhini
```

## Install dependencies

```bash
npm install
```

or

```bash
bun install
```

## Configure Environment Variables

Create a `.env` file.

```env
SUPABASE_URL=your_supabase_url
SUPABASE_ANON_KEY=your_supabase_key
```

---

## Start the development server

```bash
npm run dev
```

Open your browser:

```
http://localhost:3000
```
